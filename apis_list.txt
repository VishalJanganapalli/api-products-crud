================================================================================
PRODUCTS CRUD API - ENDPOINTS, PAYLOADS & REQUIRED FIELDS
BASE URL: https://api-products-crud-b1t1.onrender.com
================================================================================

--------------------------------------------------------------------------------
1. GET - FETCH ALL PRODUCTS OR SINGLE PRODUCT
--------------------------------------------------------------------------------
Method: GET
URL (All Products):    https://api-products-crud-b1t1.onrender.com/api/products
URL (Single Product):  https://api-products-crud-b1t1.onrender.com/api/products/:id

Headers:
  Accept: application/json

Request Payload / Body:
  NONE (No body needed. Pass filters or product ID via URL)

Note:
  Pagination has been removed. All matching products are returned directly.

Query Filter Example:
  https://api-products-crud-b1t1.onrender.com/api/products?category=Electronics&minPrice=100&isOnSale=true


--------------------------------------------------------------------------------
2. POST - CREATE A NEW PRODUCT
--------------------------------------------------------------------------------
Method: POST
URL:    https://api-products-crud-b1t1.onrender.com/api/products

Headers:
  Content-Type: application/json

=======================================================
REQUIRED FIELDS (MUST BE SENT IN POST REQUEST):
=======================================================
1. "name"          (String, required) - Product title (e.g., "Smart Fitness Band Pro")
2. "sku"           (String, required) - Unique SKU code (e.g., "FIT-BAND-001")
3. "description"   (String, required) - Detailed product description
4. "price"         (Number, required) - Positive selling price (e.g., 49.99)
5. "category"      (String, required) - Category name (e.g., "Wearables")
6. "brand"         (String, required) - Brand / Manufacturer (e.g., "NovaFit")
7. "stockQuantity" (Number, required) - Stock count, 0 or higher (e.g., 35)
8. "thumbnail"     (String, required) - Direct URL for primary product image

OPTIONAL FIELDS (WITH AUTOMATIC DEFAULTS):
- "shortDescription"        (String, default: "")
- "compareAtPrice"          (Number, default: null - original price before discount)
- "discountPercentage"      (Number, auto-calculated if compareAtPrice is given)
- "images"                  (Array of strings, default: [])
- "tags"                    (Array of strings, default: [])
- "dimensions"              (Object: { length, width, height, unit }, default: cm)
- "weight"                  (Object: { value, unit }, default: kg)
- "isFeatured"              (Boolean, default: false)
- "isNewArrival"            (Boolean, default: false)
- "isOnSale"                (Boolean, default: false / auto-set if compareAtPrice > price)
- "isBestSeller"            (Boolean, default: false)
- "isLimitedEdition"        (Boolean, default: false)
- "hasFreeShipping"         (Boolean, default: false)
- "requiresAgeVerification" (Boolean, default: false)
- "allowCustomerReviews"    (Boolean, default: true)
- "canReturn"               (Boolean, default: true)
- "displayBadge"            (String, default: "NONE" - NONE, NEW, HOT, SALE, LIMITED, BESTSELLER, CLEARANCE)
- "deliveryType"            (String, default: "STANDARD" - STANDARD, EXPRESS, SAME_DAY, DIGITAL_DOWNLOAD)
- "status"                  (String, default: "active" - active, draft, archived)

3. PUT - FULL REPLACE OF AN EXISTING PRODUCT
--------------------------------------------------------------------------------
Method: PUT
URL:    https://api-products-crud-b1t1.onrender.com/api/products/:id
Note:   Requires all mandatory fields because it replaces the whole product.

Headers:
  Content-Type: application/json

Request Payload / Body:
{
  "name": "Smart Fitness Band Pro V2",

--------------------------------------------------------------------------------
4. PATCH - PARTIAL UPDATE (UPDATE SPECIFIC FIELDS)
--------------------------------------------------------------------------------
Method: PATCH
URL:    https://api-products-crud-b1t1.onrender.com/api/products/:id
Note:   Send only the field(s) you want to modify (no required fields, everything optional).

Headers:
  Content-Type: application/json

Request Payload / Body:
{
  "price": 39.99,
  "isFeatured": true,
  "displayBadge": "SALE"
}


--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
Method: DELETE
URL:    https://api-products-crud-b1t1.onrender.com/api/products/:id

Request Payload / Body:
